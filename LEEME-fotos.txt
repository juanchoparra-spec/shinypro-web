SHINY PRO — GUÍA DE FOTOS
==========================

Para agregar o cambiar una foto, sube un archivo con EXACTAMENTE
este nombre a la carpeta "fotos" dentro de tu repo de GitHub.
No necesitas tocar el código — Netlify actualiza el sitio solo.

fotos/logo.png              → ya está incluido (tu logo)

fotos/hero.jpg               → foto principal arriba de la página (vertical, formato 4:5)
fotos/equipo.jpg             → foto del equipo (sección "Por qué Shiny Pro")

Servicios (formato horizontal, se recortan automáticamente):
fotos/servicio-residencial.jpg
fotos/servicio-profunda.jpg
fotos/servicio-mudanza.jpg
fotos/servicio-comercial.jpg
fotos/servicio-airbnb.jpg
fotos/servicio-construccion.jpg

Galería antes/después:
fotos/antes-cocina.jpg       fotos/despues-cocina.jpg
fotos/antes-bano.jpg         fotos/despues-bano.jpg
fotos/antes-sala.jpg         fotos/despues-sala.jpg

CÓMO SUBIR UNA FOTO EN GITHUB (desde el celular o compu):
1. Entra a tu repositorio en GitHub
2. Abre la carpeta "fotos"
3. Toca "Add file" → "Upload files"
4. Sube tu foto y ponle EXACTAMENTE el nombre de la lista de arriba
   (si ya existe un archivo con ese nombre, lo reemplaza automáticamente)
5. Confirma el cambio ("Commit changes")
6. Netlify publica el cambio solo, en 1-2 minutos

Mientras no subas una foto, esa sección muestra un recuadro con
el texto indicando qué foto va ahí — no rompe el diseño.
